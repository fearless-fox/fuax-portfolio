# FUAX Portfolio

3D cube-gallery portfolio — art & code by the fearless fox.

## Adding artwork

1. Drop JPGs into `assets/images/` (upload via github.com or git push).
2. Add each filename to the matching discipline in the `CATEGORIES` array at the
   top of `js/cubeGallery.js` — cube faces and the click-to-open gallery update
   automatically.

## Deploy (Netlify)

Netlify → Add new site → Import an existing project → select this repo.
No build command. Publish directory: `/`.
